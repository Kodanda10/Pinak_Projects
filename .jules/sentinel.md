## 2024-10-01 - Prevent SQL Injection in update_memory column names
**Vulnerability:** In `Pinak_Services/memory_service/app/core/database.py`, the `update_memory` method constructs an `UPDATE` query by directly interpolating dictionary keys from user-provided `updates` into the `SET` clause (`set_clause = ", ".join([f"{k} = ?" for k in serialized.keys()])`). Since keys were unvalidated, an attacker could supply keys containing malicious SQL fragments (e.g., `, content = (SELECT 'hacked'), content`) to bypass the `WHERE` clause and modify arbitrary data, such as records belonging to other tenants.
**Learning:** Even though the values were correctly parameterized using `?`, the column names (keys in the dictionary) were concatenated into the SQL statement without any sanitization or validation, leading to a severe SQL injection vulnerability.
**Prevention:** Always validate dynamically generated column names using an allowlist or ensure they strictly follow identifier constraints (e.g., using `.isidentifier()`) before interpolating them into SQL queries.
