## 2025-05-20 - SQL Injection in Dynamic UPDATE Statement
**Vulnerability:** A SQL injection vulnerability existed in `DatabaseManager.update_memory` where user-provided keys from the `updates` dictionary were directly interpolated into a dynamic `UPDATE` statement without being sanitized. An attacker could craft a payload with malformed dictionary keys to inject arbitrary SQL or bypass WHERE clause conditions.
**Learning:** The application requires dynamic UPDATE statements to patch individual columns without overriding the whole record. Although values were parameterized `f"SET {k} = ?"`, the keys `{k}` were vulnerable to injection.
**Prevention:** Always validate that dynamic column names in SQL queries strictly conform to expected constraints. When iterating over a dictionary to generate SQL clauses, ensure keys are strings and valid Python identifiers using `if not isinstance(key, str) or not key.isidentifier(): raise ValueError(...)` before constructing the query.
