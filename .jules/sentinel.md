## 2025-02-14 - Fix SQL injection in dynamic update queries
**Vulnerability:** In `Pinak_Services/memory_service/app/core/database.py`, the `update_memory` method constructs an SQL `UPDATE` statement dynamically by iterating over `updates.items()` and joining the keys to form the `SET` clause (`set_clause = ", ".join([f"{k} = ?" for k in serialized.keys()])`). The keys were not validated, allowing potential SQL injection or mass assignment if an attacker could control the keys in the `updates` dictionary.
**Learning:** This vulnerability existed because the developer correctly parameterized the values, but failed to realize that column names (keys) cannot be parameterized and must be validated explicitly before being interpolated into the query string.
**Prevention:** To avoid this next time, always enforce that dynamically provided column names are valid Python identifiers using `if not isinstance(key, str) or not key.isidentifier(): raise ValueError(...)` before constructing the dynamic SQL query.
