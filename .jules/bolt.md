## 2024-09-24 - List-based buffering for NumPy array additions
**Learning:** In `Pinak_Services/memory_service/app/services/vector_store.py`, `VectorStore.add_vectors` reallocated the `self.vectors` (and associated IDs/norms) NumPy arrays linearly using `np.vstack` and `np.concatenate` on every single vector addition. This caused O(N) reallocation overhead for each added vector, severely impacting performance for single adds (e.g. 1000 single adds took ~3.0s).
**Action:** Implemented a list-based buffering strategy (`_vector_buffer`, `_id_buffer`, `_norm_buffer`) to accumulate additions and only flush to the main NumPy arrays when necessary (e.g. before search, remove, save). This dramatically reduced reallocation overhead (1000 single adds went from ~3.0s to ~0.37s). Also learned that when summing buffered items, `sum(len(b) for b in buffer)` correctly counts individual elements in array batches.
